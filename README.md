## 👋 À propos

Salut ! Moi c’est **Mathieu** (aka **iMoDzF4N4TiK / ιMσDzF4Π4ΤιK**).  
Je développe et je modde avec une approche “propre” : structure claire, options utiles, intégration soignée et rendu crédible.

Je touche à tout ce qui fait un projet solide :
- **UI / UX** (interfaces simples et propres)
- **tooling** (outils pratiques)
- **modding** (mécaniques, configs, assets)
- **intégration** (du prototype au truc utilisable)
